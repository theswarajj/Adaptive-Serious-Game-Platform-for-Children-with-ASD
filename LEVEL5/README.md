# Level 5: Social Reasoning & Daily Living Games

---

## 1. 🏫 School Day Simulator

### In-Code Inspection & Real Name
- **Primary Game Title**: `School Day Simulator`
- **Goal / Mission**: Experience and master a full school day routine through social interaction, classroom activities, and peer cooperation.
- **Core Milestones**:
  1. Enter the school campus
  2. Meet and greet the teacher
  3. Complete a classroom activity (check bag & supplies)
  4. Ask for help politely when stuck on a worksheet
  5. Interact with a classmate
  6. Take part in a collaborative group task
  7. Enjoy playground break time
  8. Pack up and complete the school day
- **Primary Files in `LEVEL5/`**:
  - `School Day Simulator.html` / `school_day_simulator.html`
  - `school_day_simulator.py` (local server & browser launcher)

---

## 2. 🚌 Community Travel Simulator

### In-Code Inspection & Real Name
- **Primary Game Title**: `Community Travel Simulator`
- **Goal / Mission**: Travel safely to community destinations (Library, City Centre, Museum, Park, Market, School, Hospital).
- **Core Milestones**:
  1. Walk to the bus stop
  2. Read the route & timetable board
  3. Wait and board the arriving bus
  4. Greet the driver and confirm destination
  5. Pay fare (cash or tap travel card)
  6. Disembark safely at destination
- **Primary Files in `LEVEL5/`**:
  - `Community Travel Simulator.html` / `community_travel_simulator.html`
  - `community_travel_simulator.py` (local server & browser runner)

## 4. How to Run

### Option A — SkillSpark Learning Platform (Recommended)
1. Open the platform at [http://localhost:5173](http://localhost:5173).
2. Go to **Level 5: Social Reasoning**.
3. Select **School Day Simulator**, **Community Travel Simulator**, or **Shopping Adventure** and click **Play**.

### Option B — Standalone Python Launchers
```bash
# Launch School Day Simulator
python LEVEL5/school_day_simulator.py

# Launch Community Travel Simulator
python LEVEL5/community_travel_simulator.py

# Launch Shopping Adventure
python LEVEL5/shopping_adventure.py
```
Each launcher spins up a quiet, CORS-enabled local HTTP server and automatically opens the 3D game in your default browser.
